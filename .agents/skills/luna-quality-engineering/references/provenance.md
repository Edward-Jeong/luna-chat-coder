# Quality Layer Provenance

Luna Quality Engineering Layer is a Luna-native implementation informed by ideas from the MIT-licensed Paperthin project by LilMGenius.

Upstream reference:
- Project: `LilMGenius/paperthin`
- License: MIT
- Concepts reviewed: read/requirement checking, multiple perspectives, post-work self-checks, context-free review, SSOT consolidation, clean reconstruction, factual verification, and project/session catch-up.

Luna does not require Paperthin at runtime and does not globally install its skill set. The Luna implementation intentionally changes naming, orchestration, trigger conditions, severity, evidence requirements, team ownership, and completion semantics to fit Luna Chat Coder's architecture.

When copying upstream code or substantial text in future changes, preserve the upstream MIT license and attribution as required. Conceptual reimplementation should still retain this provenance note for engineering traceability.
